# Release 1.0.1

1.0.1 lets an officer connect a member's Discord account for them, from the console or from Discord. It reached production on 2026-09-17.

Compared with 1.0.0. The console panel and `/forcelink` first reached production on 2026-09-14, in builds still numbered 1.0.0; roles applied straight away arrived with the 1.0.1 build on 2026-09-17. The fixes recorded under [1.0.2](1.0.2.md) for dates, tournament points and the season label were also already in that 1.0.1 build.

## For execs and admins

- Link a Discord account to a member from the console, on the member's page. This is for a member who cannot or will not run `/link` themselves; `/link` is unchanged.
- The same from Discord with `/forcelink`. The member's club roles are applied straight away rather than at the next nightly sweep, and running it again re-applies them.
- The capability, `players.discordlink.write`, is admin only: an admin grants it to a person explicitly, and it cannot be put in a baseline.

## Under the hood

| Migration | Purpose |
| --- | --- |
| 00232 | Adds `players.discordlink.write` to the permission vocabulary. |

- A force-link is one upsert on the member's link row, so the account it displaces loses its club roles through the existing trigger.

## Before you deploy / owner steps

1. **Apply 00232.** It has no `BEGIN`/`COMMIT` of its own.
2. **Discord:** run `npm run register -w bot` once so `/forcelink` appears.
