# Release 1.0.2

1.0.2 is a batch of small fixes: dates and labels that said the wrong thing, rounded corners in the console, a clean-up for sign-ups that were never finished, and Discord commands that publish themselves. It reached production on 2026-09-18.

Compared with 1.0.1. The first five member fixes below, the single announcements list card and the `/forcelink` fix were already in the build numbered 1.0.1 that reached production on 2026-09-17; this is the release that records them.

## For members

- A date more than a week old is shown in club time, not the server's.
- A tournament points total is no longer labelled "Provisional".
- The top bar no longer names the current season while you are looking at a past one.
- A zero singles streak no longer shows as a bare "0" on your profile.
- The ladder and the profile card say which figures count since the last season rollover and which count across every season.
- Sign-ups that were never finished can be deleted after 30 days, with no email. The job ships switched off (see owner steps).

## For execs and admins

- Edit on a posted announcement fills the composer in place instead of opening a dialog, and the composer lets go if that post is deleted.
- The announcements rail is one list card, switched between website posts and Discord messages by the composer.
- Boxes in the console have rounded corners again.
- Dialog labels no longer inherit right alignment from the button that opened them.
- `/forcelink` grants the member's roles even when removing the displaced account's roles fails.

## Under the hood

| Migration | Purpose |
| --- | --- |
| 00233 | A view of sign-ups that are eligible for deletion (unfinished, 30 days after first sign-in, no matches). |

- The unfinished sign-up purge is a new Edge Function, dry-run by default. It deletes the member row before the auth user and writes an audit row between the two.
- The bot can register its slash commands when it starts, comparing with what Discord already has and updating only on a difference. It is off unless switched on.
- A refused Discord post and an unconfigured session ping are now logged with Discord's error code.

## Before you deploy / owner steps

1. **Apply 00233** (it has no `BEGIN`/`COMMIT` of its own), and deploy the `purge-unfinished-signups` Edge Function.
2. **Purge switch:** the job does nothing until `PURGE_UNFINISHED_ENABLED` is set for it. It has its own switch, separate from the inactive-account job.
3. **Command registration:** set `REGISTER_COMMANDS_ON_BOOT=true` on the production bot once to have every later deploy publish its commands. Otherwise `npm run register -w bot` is still the way.
