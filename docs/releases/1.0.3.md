# Release 1.0.3

1.0.3 brings final standings for a finished season, a handle for every member, and rounded corners in the member app. It reached production on 2026-09-19.

Compared with 1.0.2.

## For members

- The leaderboard can show the final standings of a finished season (`/leaderboard?season=...`). Only the rating is per season, so a past season's table shows rating alone, not record or streak.
- Every approved member who never chose a handle was given one, so no row on the ladder is blank.
- Cards and controls in the member app have rounded corners, matching the console's boxes.

## For execs and admins

- A season can be hidden from the Seasons page, so a retired term stays out of the public standings without deleting its archive.
- Session pings in Discord no longer depend on the role picker: the role each session group pings is a Discord setting of its own. A binding made through the picker still works as a fallback.

## Under the hood

| Migration | Purpose |
| --- | --- |
| 00234 | `seasons.hidden_flag`, so a season can be kept out of history. |
| 00235 | Gives a handle to every approved member without one. |

- The past-season ladder is read from the season's own archive, so a member who joined later never appears in a season that ended before they joined.
- Approval still does not create a handle, so a member approved after 00235 who never picks one has none until the backfill is run again.
- All 14 open Dependabot advisories are cleared, each by a patch bump (Next.js among them).

## Before you deploy / owner steps

1. **Apply 00234, then 00235.**
2. **Session pings:** set the role each session group pings. In this release that is three Discord settings keys written by hand; [1.0.5](1.0.5.md) adds `/config ping_roles` to set them from Discord.
