# Release 1.1.6

1.1.6 makes the production build about half as long, and fixes two receipt reader faults.

Compared with 1.1.5.

## For execs and admins

- A smaller re-read of a receipt adds only its amount, so a garbled second read no longer spoils the payee.
- The browser decodes a screenshot before reading it, which fixes "Error attempting to read image" on some phones.

## Under the hood

- Each image compiles only its own app, and the bot builds from its own Dockerfile. A production build takes about 5 minutes instead of 8 and a half.

## Before you deploy / owner steps

No migration.
