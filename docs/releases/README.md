# Release notes

What each release of the club app changes, for members, for execs and admins, and for whoever deploys it.

| Release | Summary |
| --- | --- |
| 1.1.8 | A paid event takes the e-transfer screenshot at sign-up, Add person, live event pages, Fees and Finances split, every exec reads everything, and the bot in any server with auto mod, `/purge` and `/event signups`. |
| 1.1.7 | Approve records the amount paid, a Form sign-up's preferred partner, and saved records as text with an Edit button. |
| 1.1.6 | A production build in half the time, and two receipt reader fixes. |
| 1.1.5 | The receipt reader learns more banks and several payee names, and old Form mappings get their waiver questions. |
| 1.1.4 | One Review button per receipt, and a Form receipt with no reference can be approved. |
| 1.1.3 | The console makes an event's Google Form, a Form's waiver signs the guest waiver, and a receipt confirms itself. |
| [1.1.2](1.1.2.md) | A club event runs as a tournament, Form non-members as guests, instant Form sign-ups, and `/softban` with a Discord server log. |
| [1.1.1](1.1.1.md) | Console commands on Discord (`/session`, `/event`), `/schedule`, a Calendar page, tournaments in the calendar feed, and passkeys in in-app browsers. |
| [1.1.0](1.1.0.md) | Membership fees and receipts, password sign-in, club events, the guided tour, the Data API service and native member apps for Android and iPhone. |
| [1.0.8](1.0.8.md) | Search the court desk, and check-in times in club time. |
| [1.0.7](1.0.7.md) | Repeat challenges count for less, match boosts, unrated events for external teams, and undo a check-in. |
| [1.0.6](1.0.6.md) | My stats follows the chosen season, the iPhone passkey tap, and faster signed-in pages. |
| [1.0.5](1.0.5.md) | Sign-in hotfix: fresh codes no longer reported expired, passkeys explained in in-app browsers. |
| [1.0.4](1.0.4.md) | The privacy release: download your data, a fuller deletion purge, Data API keys, and season fixes. |
| [1.0.3](1.0.3.md) | Final standings for a finished season, a handle for every member, rounded corners in the member app. |
| [1.0.2](1.0.2.md) | Club-time dates and label fixes, the unfinished sign-up purge, and commands registered on boot. |
| [1.0.1](1.0.1.md) | Officers link a member's Discord account, from the console or with `/forcelink`. |
| [1.0.0](1.0.0.md) | The first official release, with mass edit in the console and messages to Discord from it. |
| [0.9.0](0.9.0.md) | Retroactive label for August: the Discord bot, tournament formats, permissions and the redesign. |
| [0.8.0](0.8.0.md) | Retroactive label for the build-out to the end of July. |
